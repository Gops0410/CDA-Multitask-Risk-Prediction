# CDA Multi-Task Learning for Joint Cardiovascular and Panic Risk Prediction

M.Tech Data Science project, KPR Institute of Engineering and Technology (Anna University).
Guide: Prof. Punidha A, Assistant Professor.

## About the project
This project predicts cardiovascular risk and panic risk together using a
multi-task deep learning model with cross-domain attention (CDA). Because the
two conditions are related, the attention mechanism lets the tasks share useful
information instead of learning separately.

## Web interface
`index.html` is a single-page web app with these steps:
1. Find a patient by Patient ID
2. View patient details
3. Predict risk
4. See risk levels and how to avoid an attack
5. View health analysis
6. Get suggestions on how to improve health

## How to run
Download `index.html` and open it in any web browser. No installation is needed.

## Technologies
Multi-Task Learning, Attention Mechanisms, Deep Learning, HTML, CSS, JavaScript
